# STARGRID 3.0 全階段搭建路線

本文件描述目前已建立的全平台骨架。骨架先固定模組邊界、資料契約、權限原則與可回滾的 GitHub 交付方式；各引擎的實際服務實作依契約逐步填入。

| Phase | 範圍 | 骨架狀態 |
|---|---|---|
| 1 | GitHub 基礎架構、Monorepo、身份與權限 | 已建立 |
| 2 | Knowledge、AI Publisher、Learning、Exam Planner | 已建立 |
| 3 | Task、Calendar、Automation、Notification、History | 已建立 |
| 4 | Agent Orchestration、模型目錄、額度與審計 | 已建立 |
| 5 | Gamification、XP、金幣、成就、排行榜 | 已建立 |
| 6 | 跨引擎整合、權限與事件協調 | 已建立 |
| 7 | QA、安全、備份與正式發布 | 已建立骨架 |

「已建立」代表目錄、契約、邊界與文件已存在，不代表所有服務已可正式上線。任何未完成能力都必須維持明確的未啟用狀態。
